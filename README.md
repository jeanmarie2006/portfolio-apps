# Portfolio — applications web

Portfolio de Sedjame Vianney dédié à ses neuf applications web (Laravel, React, MySQL) : captures parcourables,
installation par QR code, méthode et architecture.

Site statique (HTML, CSS, JavaScript, sans framework). La page `index.html` est générée par `build-portfolio-apps.py`
(dépôt de travail) à partir des données des projets.

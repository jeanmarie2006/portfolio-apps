Méthode

Un même chemin, neuf fois.

  1. 01

    Cadrer

    Je pars du cahier des charges à la lettre : fonctionnalités de base, puis bonus. Chaque règle métier est écrite avant le premier écran.

  2. 02

    Construire

    API Laravel, authentification Sanctum, validation serveur, puis interface React mobile d’abord, accessible au clavier et au toucher.

  3. 03

    Éprouver

    Tests PHPUnit et Vitest, puis parcours complets pilotés dans un vrai navigateur : chaque bug trouvé devient un test.

  4. 04

    Livrer

    Mise en ligne, application installable, README avec captures, collection Postman et code publié sur GitHub.

Sous le capot

Ce qui se passe derrière l’écran.

Sept des neuf applications partagent la même architecture : une interface React installable qui dialogue en JSON avec une API Laravel, adossée à MySQL.
